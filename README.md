# Microsoft 365 Copilot rollout starter

A short, free planning checklist and a set of starter prompts for a first Microsoft 365 Copilot pilot.

This is an independent resource from The Copilot Workshop. It is not affiliated with or endorsed by Microsoft. Microsoft already publishes free Copilot training and documentation; use those for product behavior and admin how-to. This repo is only a planning aid: it helps a team write down owners, evidence, and a go / hold / stop decision before a pilot grows.

## What's in here

- [CHECKLIST.md](CHECKLIST.md) — a one-page planning checklist (pilot scope, readiness, communications, review date).
- [PROMPTS.md](PROMPTS.md) — ten starter prompts for planning and everyday checks, each with a "use it when" note and a check to run on the answer.

None of this is legal, security, or compliance advice. It does not replace your existing policies, Microsoft Learn guidance, or a review by the people who own your tenant.

## How to use the checklist

Copy [CHECKLIST.md](CHECKLIST.md) into your project notes. Fill the owner and date columns. Leave any row on HOLD until the named owner has reviewed the evidence. If your existing project documents already cover a row, keep those and skip the row.
