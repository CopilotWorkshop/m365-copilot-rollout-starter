# Copilot pilot planning checklist

Use this as a starting document, not as proof that a tenant is ready, secure, or compliant. If your organization already has a rollout plan, keep that plan and only borrow any row you are missing.

Status values: `Not started` | `HOLD` | `Go` | `Stop`.

## 1. Scope and ownership

| Item | Notes / evidence | Owner | Review date | Status |
| --- | --- | --- | --- | --- |
| Pilot group (named teams or roles, not "everyone") |  |  |  |  |
| What "useful" looks like for this pilot (one or two observable examples) |  |  |  |  |
| Who can make the go / hold / stop call to expand, pause, or stop |  |  |  |  |
| Who answers "is this an approved use of Copilot?" questions |  |  |  |  |
